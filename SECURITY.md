# Security

Report a vulnerability in the ASPERN service, its MCP server or its API to
**hello@aspern.org** (English or Czech). The machine-readable contact is
https://aspern.org/.well-known/security.txt.

Please include the endpoint or tool, the request you sent, what you expected and what
happened. Do not test against other people's data and do not send load that degrades the
service for others.

ASPERN is read-only: it never holds or signs for user funds and never asks for keys or seed
phrases. Anything claiming to be ASPERN that asks for them is not us.
